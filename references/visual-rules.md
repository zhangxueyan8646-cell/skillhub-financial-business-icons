# 已观察到的视觉特征与复用规则

## 已证实来源

23 个根节点尺寸均为60×60；21个完整SVG，2个组合，共25份原始SVG。原始SVG为MasterGo导出格式，包含填充路径、clipPath、渐变、滤镜及部分描边；不能概括为统一线性图标。逐图颜色、描边、圆角、滤镜记录在 icon-index.json，数值是导出属性，不代表全局设计token。

- 原稿呈蓝色叠层/半透明前景与深蓝后景；浅紫蓝方形底色。常见背景渐变为 #F5F7FF → #EEEFFF，纵向180°。
- 常见图形颜色 #85AAFE、#0D59C4，白色文字/符号；另有 #F8FFFF、#FFFEFF、#FBFDFF、#E1E7EB。保留每个SVG内部定义，不能把所有颜色统一替换成一个主题色。
- 实测stroke-width有0.75、0.8888888955等多个值以及约0.5333–1.2104的其他值；很多边缘是填充路径，没有stroke属性。不要统一成1px或2px。
- 外层clip矩形多为rx=0；内部圆角、圆形半径多样，详见逐项索引；不能把圆形半径误当成控件圆角。
- 留白和重心因图形不同；不裁掉底色、不按不透明像素重新居中。港股资金面组合图形35×35.13、定位13/13；ETF最终前景35.25×30、定位12.75/15.15。两例不是全库通用安全区。
- 港股组合包含白色H，17.5px、600、24px行高；ETF白字10px、600、14px行高。快照字体为PingFang SC，无法使用该字体的目标端需重新比对；新建MasterGo文本须遵循其字体查询规则。

## 文件使用

assets/originals 保存原始SVG字节，不覆盖；assets/compositions 保存23个可预览包装，路径为相邻 ../originals。21个完整SVG优先直接使用索引reusePath。2个组合使用整个包装内容（去除文档头，保留完整60×60结构），依赖目录必须一起复制。若目标只支持单个SVG，应明确需要完整组合导出/转换，不能声称当前已有两个完整SVG。

组合使用其他尺寸时，将60×60内部容器整体scale(size/60)，transform-origin:top left，外部占位尺寸设为size×size。不独立放大字体或描边。不主动更改尺寸、颜色或去背景；用户尚未确认允许调整范围。

## 已知导出差异

2026-09-30在Chrome比对原稿PNG：部分原始SVG的背景模糊/重叠区出现额外边缘或深色块，原始导出在浏览器中的视觉并非与MasterGo截图完全一致。保留SVG中的原始滤镜，不为了单一浏览器擅自删改。对像素一致要求严格的交付，可在用户接受位图时使用原稿PNG，或安排目标端的矢量适配并另存衍生版。

港股资金面导出的“组1072”定位left=35px导致圆形溢出；compositions/3-218.html中已改为left=0px，保留父级13px。这是根据原稿进行的位置适配，原始sourceHtml和SVG未改。该组合仍受滤镜和字体差异影响。

ETF源结构有多个重叠背景和图形层；原样保存。不要因存在多个层就将它们认定为不同状态或删去认为多余的层。

MasterGo预览PNG用于核对造型；不得自动转描、截图替代原矢量或声称恢复了设计工具内全部可编辑属性。
